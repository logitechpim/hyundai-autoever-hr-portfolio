# DAY ZERO: 시스템을 복구하라

지원자 이준호의 현대오토에버 신입사원 온보딩 미실행 HRD 프로그램 제안입니다. 공식 프로그램이나 실제 장애 대응 지침이 아니며 교육 효과는 미검증입니다.

## 실행

index.html을 브라우저에서 열면 됩니다. 외부 라이브러리, 이미지, 계정 또는 서버 없이 실행됩니다. 팀 4명이 한 기기를 함께 사용하도록 설계했으며 온라인 실시간 멀티플레이는 구현하지 않았습니다.

## 산출물

- 5개 미션과 분기 엔딩, 35분·12분·무제한 모드의 게임
- 학습 목표, 미션 설계, 75분 교육과정, 예산 가정, 평가 체계의 HRD 기획 페이지
- 진행자 운영 가이드, 역할 카드 4종, 해설, 관찰표, A/B형 평가 문항

페이지에서 HTML 게임, 운영 가이드 텍스트, 결과 JSON을 내려받을 수 있습니다. 기획안·가이드·역할 카드는 인쇄할 수 있습니다.

진행 상태는 현재 브라우저의 localStorage에만 저장됩니다. 기록은 서버로 전송하지 않습니다. 최초 제출 점수는 게임의 판단 기록이며 실제 협업, 교육 효과 또는 개인 업무 역량 점수가 아닙니다.

## 검증

상태 모델의 11개 시나리오: 정상 완료, 오답 재시도, 선택별 엔딩, 단서 공유 제약, 최종 선택 수 제약, 시간 초과, 일시정지, 무제한 모드, 시각 앞자리 0 유지. 브라우저 전체 흐름 검증은 시연 배포 후 수행합니다.

## 공개 자료

현대오토에버 공식 홈페이지, Service SW 직무 소개, 차량 연동 서비스, SDF(Factory), 2022년 2분기 실적 발표. 자료 확인 2026-10-11. 세부 URL과 공개 사실/가상 설정의 구분은 HRD 기획 페이지에 있습니다.
